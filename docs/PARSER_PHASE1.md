# PNR parser foundation: Phase 1

The reusable parser contract lives in `types/pnr.ts`. `ParsedField<T>` carries a nullable value, confidence state, source evidence and issue codes. `FlightRecord` stores the raw status and reservation booking designator (RBD) separately from cabin; an unverified cabin remains `null`. `ParseResult` preserves ordered passengers, itinerary records, diagnostics and original physical lines. These are contracts for the next parser implementation, not output from the current converter.

`lexPnr(raw)` in `lib/parser/lexer.ts` returns physical lines and tokens without trimming, case conversion or whitespace normalization. Lines are 1-based, including a final empty line after a trailing newline. Spans use JavaScript UTF-16 indexes: offsets are 0-based and end-exclusive; columns are 1-based and end-exclusive. Line spans exclude the newline, while each line retains its exact `newline` delimiter (`CRLF`, `CR`, `LF` or empty). Tokens represent words, digits and individual symbols; spaces and tabs stay in each `raw` line. Exact input can be rebuilt by joining each line's `raw + newline`.

`tests/fixtures/pnr.ts` contains redacted golden excerpts for the five existing Sabre and Galileo regression cases. Each fixture declares `id`, `gds`, `raw` and handwritten `expected`: passenger/flight/ARNK counts, passenger names, flight numbers and routes, original booking status and RBD, and inclusive physical line ranges with source excerpts. The legacy converter tests now read these same samples. Lexer tests verify reconstruction, offsets, source excerpts, statuses, RBDs, mixed newlines and a synthetic 120-passenger/80-segment payload.

The current `parsePnr` in `lib/converter.ts` has **not** been switched to this contract. Its old output does not expose source spans or original RBD/status as structured fields. Future phases must build the separate Sabre, Galileo and Amadeus grammars, resolve wrapped records, cross-check all fields against fixtures, validate cabin only using authoritative carrier-specific mapping, and integrate the parser into saving and exports. Add independently checked Amadeus, group and malformed-input fixtures before claiming comprehensive coverage. These fixtures assert source facts, not universal GDS accuracy or production performance.
