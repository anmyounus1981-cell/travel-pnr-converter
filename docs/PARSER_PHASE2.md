# GDS grammar milestone: Phase 2

`lib/parser/index.ts` exposes `parseStructuredPnr(raw)`. It lexes the input, scores system-specific evidence through `detector.ts`, then dispatches to independent `sabre.ts` and `galileo.ts` grammar state machines. `DetectionResult` records system, confidence, candidate scores, physical source spans and ambiguity. Conflicting Sabre/Galileo signals return `unknown` rather than selecting whichever marker appears first. Amadeus identification is recognized but deliberately blocks until its dedicated grammar is implemented.

Both grammar modules collect numbered passenger entries without a fixed upper bound, track an open numbered segment and join only its physical continuation lines. They retain original source lines and use the first and last physical line for each record span. Sabre `/DC…` continuation and explicit arrival-date markers, Galileo split flight numbers, `#` next-day markers, space-before-dot numbers and ARNK have golden assertions. Unmatched numbered segments become `unparsed` itinerary records with `review` diagnostics. Missing passenger lists, missing flights and missing arrival times are `blocking`; unknown, conflicting and unsupported input is returned with original raw lines and a blocking reason. Flight year, time zone, passenger type and cabin are unverified; a booking code is never mapped to Economy or Business without authoritative evidence.

The supported grammar covers only the five redacted Sabre/Galileo shapes in `tests/fixtures/pnr.ts`, plus synthetic group input. It does not infer a missing flight year, validate airport-specific local times, parse hotel/fare data, resolve carrier RBD mappings or cover Amadeus layouts. Ancillary Sabre/Galileo footer sections are recognized as non-itinerary metadata; they are not treated as fare rules. The live converter, database save and exports still call `lib/converter.ts`. Phase 3 must add independently verified Amadeus fixtures, broader GDS record variants, strict field validation and a reviewed adapter before switching live behavior.
